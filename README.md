# LED-Holder-for-electronics-focus

This is my first project. Its practicaly a LED Holder which shines light over my electronics when I am working and helps me see some more detail.  I made a prototype with lego, and thats where I took the dimensions from to make it exact. In the lego model, the led wasnt really adjustable, like it the whole build slid up and down on the table but the LED itself wasnt actually adjustable, So i have designed a ball hinge system where I can move it around
